# Vibe Forge AR

A Meta Quest 3 mixed-reality application built with Unity, OpenXR, Meta XR Interaction SDK, and MRUK.

## Project documents

- [Step-by-step build guide](VIBE_FORGE_AR_BUILD_GUIDE.md)
- [Source research](VR%20Game%20Learning%20with%20Codex.md)

The first playable milestone launches into passthrough, previews a valid point on the physical environment, places a forge object with the right controller trigger, and lets the player grab and move it.
